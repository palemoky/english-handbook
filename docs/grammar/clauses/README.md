# 复合句

复合句由主句和从句组成，从句按在句子中的作用分为三类：

- [定语从句](relative.md)：修饰名词，相当于形容词
- [名词性从句](nominal.md)：充当主语、宾语、表语、同位语，相当于名词
- [状语从句](adverbial.md)：表示时间、原因、条件等，相当于副词

判断一个从句属于哪一类，看它在句子中充当什么成分：

| 从句 | 充当的成分 | 示例 |
| --- | --- | --- |
| 定语从句 | 修饰前面的名词 | the book **that I bought** |
| 名词性从句 | 主语、宾语、表语、同位语 | I know **that he is right**. |
| 状语从句 | 修饰整个主句，表示时间、原因、条件等 | **When I got home**, it was dark. |
