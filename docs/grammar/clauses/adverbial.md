# 状语从句

状语从句在句中起副词的作用，修饰主句的谓语或整个主句，表示时间、原因、条件等。

## 分类

| 类型 | 连接词 | 示例 |
| --- | --- | --- |
| 时间 | when、while、as、before、after、until、since、as soon as | I'll call you **when I arrive**. |
| 地点 | where、wherever | Sit **wherever you like**. |
| 原因 | because、since、as | I stayed home **because I was ill**. |
| 条件 | if、unless、as long as | **If it rains**, we'll stay home. |
| 让步 | although、though、even though、even if、while | **Although he is rich**, he isn't happy. |
| 目的 | so that、in order that | Speak louder **so that everyone can hear you**. |
| 结果 | so … that …、such … that … | He was **so** tired **that** he fell asleep. |
| 比较 | than、as … as … | She runs faster **than I do**. |
| 方式 | as、as if、as though | He talks **as if he knew everything**. |

状语从句放在主句前面时，通常用逗号隔开；放在后面时一般不用逗号。

## 主将从现

在 **时间** 和 **条件** 状语从句中，如果主句是将来时，从句要用 **一般现在时** 表示将来：

| ✓ | ✗ |
| --- | --- |
| I'll call you when I **arrive**. | I'll call you when I will arrive. |
| If it **rains** tomorrow, we'll stay home. | If it will rain tomorrow, we'll stay home. |
| I'll wait until he **comes** back. | I'll wait until he will come back. |

## 易混淆的用法

### 不能同时使用的连词

- although / though 不能与 but 连用：**Although** he is rich, he isn't happy. ✓ / Although he is rich, but he isn't happy. ✗
- because 不能与 so 连用：**Because** it rained, we stayed home. ✓ / Because it rained, so we stayed home. ✗

中文习惯说“虽然……但是……”“因为……所以……”，英语中只能保留其中一个。

### until 与 not … until

| 结构 | 搭配的动词 | 示例 |
| --- | --- | --- |
| until | 延续性动词（wait、stay、live），表示动作持续到某时 | I waited **until** he came. |
| not … until | 短暂性动词（leave、arrive、start），表示直到某时才发生 | He **didn't** leave **until** ten o'clock.（他直到十点才走） |

### so … that 与 such … that

| 结构 | 后接 | 示例 |
| --- | --- | --- |
| so … that | 形容词或副词 | The box is **so heavy that** I can't lift it. |
| such … that | （a / an +）形容词 + 名词 | It is **such a heavy box that** I can't lift it. |

### 一词多义的连词

| 连词 | 含义 | 示例 |
| --- | --- | --- |
| since | 自从（时间） | I have lived here **since** I was a child. |
| | 既然（原因） | **Since** you're here, let's begin. |
| as | 当……时（时间） | **As** I was leaving, the phone rang. |
| | 因为（原因） | **As** it was late, we went home. |
| | 像……一样（方式） | Do **as** I say. |
| while | 当……时（时间，与进行时连用） | **While** I was cooking, he called. |
| | 然而（对比） | I like tea, **while** my wife likes coffee. |

连词的完整列表见[连词](../parts-of-speech/conjunction.md)。
