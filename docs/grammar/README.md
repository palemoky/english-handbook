# 语法概览

## 语法框架

英语语法可以从三个层面来把握：

- **10 种词性**：单词按用法分类，记住单词的词性，才能分析和理解句子
- **9 种句子成分**：主语、谓语、宾语、双宾语、表语、宾语补足语、定语、状语、同位语，见[句子成分](sentence-structure/elements.md)
- **句型**：简单句可归为[五大基本句型](sentence-structure/patterns.md)，复杂句子则由[复合句](clauses/README.md)扩展而来

### 10 种词性

| 词性 | 缩写 | 说明 |
| --- | --- | --- |
| 名词 noun | n. | 人、事物、地点或抽象概念的名称 |
| 代词 pronoun | pron. | 代替名词，如 we、that、all、who |
| 数词 numeral | num. | 表示数量或顺序 |
| 冠词 article | art. | 定冠词 the 特指，不定冠词 a / an 泛指，通常用在名词前 |
| 动词 verb | v. | 分为及物动词（后接宾语）和不及物动词（后不接宾语） |
| 形容词 adjective | adj. | 修饰名词，通常放在名词之前 |
| 副词 adverb | adv. | 修饰动词、形容词、其他副词或整个句子 |
| 介词 preposition | prep. | 用在名词、代词或动名词前，如 at、in、on |
| 连词 conjunction | conj. | 连接词、短语或句子，如 and、but、or |
| 感叹词 interjection | int. | 表示感叹，如 oh、wow |

各词类的详细用法见[词类](parts-of-speech/README.md)。
