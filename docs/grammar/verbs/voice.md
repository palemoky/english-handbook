# 语态

主动语态变化的是 **时间**，被动语态在此基础上把 **状态** 换成被动形式：

| 主动 | 被动 |
| --- | --- |
| do | be done |
| be doing | be being done |
| have done | have been done |
| have been doing | have been being done |

## 被动语态的 16 种形式

| 时间 \\ 状态 | 一般（simple）<br>be done | 进行（progressive）<br>being done | 完成（perfect）<br>have been done | 完成进行（perfect progressive）<br>have been being done |
| --- | --- | --- | --- | --- |
| 过去（past） | was/were done | was/were being done | had been done | had been being done |
| 现在（present） | am/is/are done | am/is/are being done | have/has been done | have/has been being done |
| 将来（future） | shall/will be done | shall/will be being done | shall/will have been done | shall/will have been being done |
| 过去将来（future in the past） | should/would be done | should/would be being done | should/would have been done | should/would have been being done |

!!! note
    完成进行时的被动形式（have been being done）以及将来进行时的被动形式（will be being done）在实际中极少使用。

被动语态中，动作的执行者用 by 引出，如 The window was broken by Tom.

主动语态的 16 种形式见[时态](tenses.md)。
