# 动词体系

动词是英语句子的核心，也是语法中变化最多的部分。

- [时态](tenses.md)：动作发生的时间和状态
- [语态](voice.md)：主动与被动
- [情态动词](modals.md)：can、must、should 等表达能力、义务、推测的动词
- [非谓语动词](non-finite.md)：不定式、动名词、分词
- [虚拟语气](subjunctive.md)：表达假设、愿望等与事实相反的情况

## 动词的分类

按在句子中的作用，动词分为三类：

| 类别 | 说明 |
| --- | --- |
| 谓语动词 | 在句中作谓语，决定句子的基本句型 |
| 助动词 | 帮助谓语动词表达时态、语态、否定和疑问，见[情态动词 · 助动词](modals.md#助动词) |
| 非谓语动词 | 不定式、动名词、分词，不能单独作谓语，见[非谓语动词](non-finite.md) |

谓语动词按后面接什么成分，又分为五种，正好对应[五大基本句型](../sentence-structure/patterns.md)：

| 谓语动词 | 句型 |
| --- | --- |
| 不及物动词 | 主语 + 动词 |
| 单及物动词 | 主语 + 动词 + 宾语 |
| 双及物动词 | 主语 + 动词 + 间接宾语 + 直接宾语 |
| 复杂及物动词 | 主语 + 动词 + 宾语 + 宾语补足语 |
| 系动词 | 主语 + 系动词 + 表语（主语补足语） |

谓语动词通过变化 **时间**（现在、过去、将来、过去将来）和 **状态**（一般、进行、完成、完成进行）组合出 4 × 4 = 16 种[时态](tenses.md)。
