# 非谓语动词

非谓语动词不能单独作谓语，包括不定式、动名词和分词。

## 不定式

不定式由 to do / to be done 构成，在句中可以起名词、形容词、副词的作用。

不定式常用于形容词和以下动词之后：agree、decide、hope、plan、promise 等。

## 动名词与现在分词

两者形式相同（都是 doing），但功能不同：

- **动名词** 起名词的作用，在句中作主语、宾语、表语、定语等
- **现在分词** 与 be 构成进行时作谓语，也可以作定语、表语和状语

动名词常用于介词和以下动词（短语）之后：avoid、advise、consider、enjoy、escape、mind、practice、suggest、miss、insist on、give up、feel like、put off 等。

-ing 形式的变化规则见[动词 · 形式](../parts-of-speech/verb.md#现在分词和动名词)。

## 不定式与动名词的区别

start、begin、continue、like、love、hate、prefer 等动词后，不定式和动名词可以互换，但语义略有不同：

- 不定式更多地表示一个具体的目标或意图
- 动名词更侧重于描述一种持续的行为或习惯

## 过去分词

过去分词表示被动或完成：

- 与助动词 have 构成完成时、完成进行时
- 与 be 构成被动语态
