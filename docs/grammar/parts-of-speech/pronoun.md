- 第二人称单复数除反身代词外都同形：you / your / yours。
- 多个人称并列时，顺序一般是：第二人称 → 第三人称 → 第一人称，如 you, he and I。
- it 除了指代上文提过的某物，也用于指代不知道性别的人，如婴儿。
- 一般现在时中，主语的人称和单复数决定动词形式，见[动词 · 人称变化](verb.md#be-have-do)。

所有格形容词后面必须接名词，所有格代词单独使用：

| 所有格形容词 | 所有格代词 |
| --- | --- |
| This is **my** bag. | This bag is **mine**. |
| It is **our** idea. | The idea is **ours**. |
| That is **your** pen. | That pen is **yours**. |
| **His** eyes are blue. | Ben is a son of **his**. |
| I like **her** kindness. | Ann lent **hers** to me. |
| **Their** hats look nice. | **Theirs** look cooler. |

its 作所有格代词几乎不单独使用。

## 指示代词

| | 较近的人或物 | 较远的人或物 |
| --- | --- | --- |
| 单数 | this | that |
| 复数 | these | those |

其它指示代词还有：

- such：上文提到的某人某物
- same：上文提到的相同的某人某物
- it：不清楚的某人某物

## 疑问代词

| 疑问代词 | 用法 |
| --- | --- |
| what | 什么，询问物品、事情或情况 |
| who | 谁，作主语，询问身份 |
| whom | 谁，作宾语 |
| whose | 谁的，询问所有权 |
| which | 哪个，用于比较或选择 |
| whatever、whichever、whoever、whomever | 无论什么/哪个/谁 |

why（为什么）、how（如何）也常用于提问，但它们是疑问副词。各疑问词的提问对象见[句子类型 · 特殊疑问句](../sentence-structure/types.md#特殊疑问句)。

## 不定代词

代替或修饰不确定的人或物，可以作主语、宾语、表语、定语、状语。

| 类别 | 不定代词 |
| --- | --- |
| 单数 | some、any、each、every、either、neither 等 |
| 复数可数 | many、few、ones、both、others 等 |
| 不可数 | much、little、all 等 |
| 复合 | something、someone、nothing、nobody 等 |

| 不定代词 | 含义 | 修饰可数名词 | 修饰不可数名词 |
| --- | --- | --- | --- |
| some | 肯定句表几个、一些、某个；疑问句表建议、请求、希望 | ✓ | ✓ |
| any | 肯定句表任何的；疑问句或否定句表任何一些、任何一个 | ✓ | ✓ |
| no | 作定语，表示没有 | ✓ | ✓ |
| none | 作主语、宾语、表语，表示没有一个人/物；指人指物都可以，后面能跟 of，谓语单复数均可 | ✓ | ✓ |
| no one / nobody | 指人，后面不能跟 of，谓语用单数 | | |
| all | 三者或三者以上的人或物 | ✓ | ✓ |
| both | 两个人或物 | ✓ | |
| every | 三个或三个以上的整体中的每一个，侧重 **整体** | ✓（单数） | |
| each | 两个或两个以上中的每一个，强调 **个别** | ✓（单数） | |
| either | 两个中的任何一个 | ✓（单数） | |
| neither | either 的否定形式，两个都不 | ✓（单数） | |
| many | 很多 | ✓（复数） | |
| much | 很多 | | ✓ |
| few / a few | few 表否定，很少几个；a few 表肯定，有几个 | ✓ | |
| little / a little | little 表否定，少到几乎没有；a little 表肯定，有一些 | | ✓ |
| a lot of、lots of、plenty of | 很多 | ✓（复数） | ✓ |
| a number of、a large number of | 许多 | ✓（复数） | |
| a great deal of | 大量 | | ✓ |

### other 与 another

| 不定代词 | 含义 |
| --- | --- |
| other | 不同种类的另一个，其余的 |
| the other | 两个中的另一个 |
| another | 同种类的另一个，又一个 |
| others | 其余的人或物，指一部分 |
| the others | 其余的人或物，指全部 |

### 复合不定代词

| 构成 | 用法 |
| --- | --- |
| some- / every- 开头 | 用在肯定句中 |
| any- 开头 | 用在否定句、疑问句和条件状语从句中 |
| no- 开头 | 本身表否定 |
| -thing 结尾 | 指物 |
| -one / -body 结尾 | 指人 |

## 相互代词

表示相互关系：each other、one another。

## 关系代词

引导[定语从句](../clauses/relative.md)，并在从句中充当主语或宾语：

| 关系代词 | 指代 | 在从句中的作用 |
| --- | --- | --- |
| who | 人 | 主语 |
| whom | 人 | 宾语 |
| which | 物 | 主语或宾语 |
| that | 人或物，相当于 who、whom、which | 主语或宾语 |

## 连接代词

引导[名词性从句](../clauses/nominal.md)（主语从句、宾语从句、表语从句）：what（什么）、who（谁）、which（哪个）、whose（谁的）等。
