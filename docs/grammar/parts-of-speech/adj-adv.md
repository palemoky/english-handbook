# 形容词与副词

## 形容词

形容词用于修饰名词，通常放在名词之前。

### 分类

| 类别 | 说明 | 示例 |
| --- | --- | --- |
| 属性 | 表示人和物具有的属性，可以用 very 修饰 | beautiful |
| 类别 | 表示事物的类别，不能用 very 修饰 | empty、Chinese |
| 颜色 | 浅色前加 light、pale、bright，深色前加 dark、deep | light blue、dark red |
| 强调 | 加强语气 | absolute、utter、total、entire |
| -ing 与 -ed | 由分词转化而来，见下文 | boring、bored |
| 复合 | 形容词 + 名词 + -ed；形容词/副词 + 过去分词；形容词/副词/名词 + 现在分词；名词 + 形容词 | kind-hearted、well-known、good-looking、snow-white |

### -ing 与 -ed

-ing 形容词描述事物本身的特点（令人……的），-ed 形容词描述人的感受（感到……的）：

| -ing | -ed |
| --- | --- |
| amusing（有趣的） | amused（被逗乐的） |
| interesting（有趣的） | interested（感兴趣的） |
| exciting（令人兴奋的） | excited（感到兴奋的） |
| boring（无聊的） | bored（感到无聊的） |

### 多个形容词的顺序

多个形容词修饰同一个名词时，一般按以下顺序排列：

| 顺序 | 类别 | 示例 |
| --- | --- | --- |
| 1 | 限定词 | a、an、the、my、your、our |
| 2 | 描绘 | beautiful、boring |
| 3 | 大小长短 | big、small、tall、short |
| 4 | 形状重量 | round、fat、skinny |
| 5 | 状态 | cold、wet、rich |
| 6 | 新旧 | new、old、ancient |
| 7 | 颜色 | yellow、red、blue |
| 8 | 图案 | spotted、flowery |
| 9 | 国籍 | Chinese、American、Australian |
| 10 | 材料 | wooden、paper、platinum |
| 11 | 用途、类别 | working、sleeping、classic |

如 a beautiful small old Chinese wooden table。

以上是形容词作前置定语的情况。修饰 somebody、anybody、everything、nothing 等复合不定代词时，形容词要后置，如 something interesting。形容词短语一般也放在被修饰的名词之后。

### 比较级与最高级

#### 变化规则

| 规则 | 示例 |
| --- | --- |
| 单音节词和少数双音节词，加 -er / -est | warm → warmer → warmest |
| 以 e 结尾，加 -r / -st | large → larger → largest |
| 重读闭音节，末尾只有一个辅音字母，双写该字母再加 -er / -est | big → bigger → biggest |
| 辅音字母 + y 结尾，变 y 为 i 再加 -er / -est | happy → happier → happiest |
| 多音节词和部分双音节词，前面加 more / most | fantastic → more fantastic → most fantastic |

#### 常见用法

- 比较级可以单独使用，与 than 连用比较两者，前面可以加 a lot、much、rather、a little、even 等修饰
- 最高级前面要加 the，前面可以加 by far、almost、much 等修饰
- at + 最高级表示处于最……的状态，如 at least、at most、at best
- 比较级 and 比较级，表示越来越……：faster and faster；多音节词只写一次 more：more and more fantastic
- the + 比较级 …, the + 比较级 …，表示越……就越……：The richer, the better.

#### 含 more than 的表达

| 表达 | 含义 | 示例 |
| --- | --- | --- |
| more than + 名词 | 不仅仅是（= not only） | We are more than friends. |
| more than + 数词 | 超过（= over） | More than one billion people live in China. |
| more than + 形容词 | 非常（= very） | We are more than happy to help. |
| no more than | 只有，仅仅（强调少） | I have no more than four games. |
| not more than | 不超过（≤） | I have not more than four games. |
| no more … than … | 两者都不（= neither … nor …） | He is no more a scientist than I am. |
| not more … than … | 不如（= not so … as …） | I am not more careful than you. |

### 易混形容词

| 词语 | 区别 |
| --- | --- |
| too much / much too | too much 侧重数量过多，修饰名词：The food is too much for me to finish.<br>much too 强调程度过高，修饰形容词或副词：The coffee is much too hot to drink. |
| good / well | good 是形容词，可表示道德、品质；well 通常是副词，作形容词时表示身体健康 |
| nice / fine | nice 表示令人愉悦，指人或物的性质、外表、品质；fine 多指身体或天气 |
| lonely / alone | lonely 表示心理上的孤独；alone 表示物理上的独自 |
| quick、fast / soon | quick 和 fast 表示速度快；soon 表示时间上很快 |
| interesting / interested | interesting 表示令人感兴趣；interested 表示对……感兴趣 |
| living / alive / live / lively | living 表示活着的，也可作前置定语；alive 表示活着的，只作表语或后置定语；live 表示活的（多指动物）、现场直播的；lively 表示活泼、生动 |

## 副词

副词在句子中提供额外的信息，帮助理解动作、状态的时间、方式、地点或程度等细节，可以修饰动词、形容词、其他副词或整个句子。

### 分类

| 类别 | 示例 |
| --- | --- |
| 地点 | here、there、home、upstairs、downstairs、anywhere、everywhere、nowhere、somewhere、abroad、elsewhere |
| 位置 | above、below、down、up、out、in、across、back、along、over、round、around、away、near、off、on、inside、outside、past |
| 方式 | carefully、properly、anxiously、suddenly、normally、fast、calmly、politely、proudly、softly、warmly、slowly、badly |
| 程度 | nearly、rather、very、too、fully、almost、extremely、absolutely、slightly、simply、awfully、deeply、really、perfectly、quite、much |
| 疑问 | how、when、where、why |
| 强调（强调形容词或副词） | completely、perfectly、really、totally、mainly、only |
| 连接（引导名词性从句或连接并列结构） | how、when、where、why、then、however、therefore |
| 关系（引导定语从句） | when、where、why |
| 句子（修饰整个句子） | actually、personally、certainly、definitely |

### too、also、either、nor

都表示“也”，但位置和句式不同：

| 副词 | 使用方式 | 例句 |
| --- | --- | --- |
| too | 肯定句和疑问句句尾，用逗号隔开 | Are you Chinese, too? |
| also | 肯定句中，实义动词之前，系动词和助动词之后 | You are also Chinese. |
| either | 否定句句尾，用逗号隔开 | I am not lucky, either. |
| nor | 放在句首，后面的句子部分倒装 | I can't swim. Nor can he. |

### 易混副词

| 副词 | 含义 | 例句 |
| --- | --- | --- |
| sometimes | 有时候 | Sometimes I go shopping in the mall. |
| sometime | 将来（或过去）的某个时候 | Peter, I will meet your mother sometime. |
| some times | 几次 | You have treated me quite some times recently. Now it's my turn. |
| some time | 一段时间 | I should stay at home for some time. |
| farther | 具体的远 | Can we walk farther tomorrow? |
| further | 抽象的远，进一步 | See below for further information. |
