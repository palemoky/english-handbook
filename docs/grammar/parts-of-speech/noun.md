# 名词

## 分类

| 分类 | 说明 | 示例 |
| --- | --- | --- |
| 专有名词 | 人名、地名、国家、组织、单位、大型活动、著名事件等，大多不可数 | Beijing、the United Nations |
| 普通名词 | 专有名词以外的名词 | book、teacher |
| 可数名词 | 可以加数词，有单复数；可以加定冠词和不定冠词 | apple、egg、tree、family、class、team |
| 不可数名词 | 只有单数形式；只能加定冠词 | water、fire、time、hope |
| 具体名词 | 可数与不可数都有 | car、book、water |
| 抽象名词 | 大多不可数 | time、hope、love、anger |

## 复数

### 规则变化

| 单数结尾 | 复数变化 | 示例 |
| --- | --- | --- |
| 大多数 | 加 -s | day → days |
| s、x、z、ch、sh | 加 -es | bus → buses，box → boxes，watch → watches，dish → dishes |
| 辅音字母 + y | 变 y 为 i 再加 -es | city → cities |
| f / fe | 多数变 f 为 v 再加 -es，少数直接加 -s | half → halves，leaf → leaves，knife → knives，wife → wives，life → lives，loaf → loaves；roof → roofs |
| ch 发 /k/ | 加 -s | stomach → stomachs |
| 辅音字母 + o | 多数加 -es | hero → heroes，potato → potatoes，tomato → tomatoes，echo → echoes |
| 元音字母 + o，或外来词 | 加 -s | zoo → zoos，bamboo → bamboos，radio → radios，photo → photos，piano → pianos |

### 不规则变化

| 单数 | 复数 |
| --- | --- |
| person | people |
| man / woman | men / women |
| child | children |
| tooth / foot / goose | teeth / feet / geese |
| mouse | mice |
| datum | data |
| thesis / analysis / diagnosis / oasis / crisis | theses / analyses / diagnoses / oases / crises |

### 复合名词

| 规则 | 示例 |
| --- | --- |
| 以不可数名词结尾，没有复数 | homework、software |
| man 或 woman 作前缀，前后都变复数 | man actor → men actors |
| 两个名词组合，后一个变复数 | bus stop → bus stops |
| 可数名词 + 介词（短语），前一个名词变复数 | sister-in-law → sisters-in-law |
| 动词 / 过去分词 + 副词，末尾加 -s | stand-by → stand-bys，grown-up → grown-ups |

### 单复数同形与只有复数

- 单复数同形：fish、deer、sheep、species、Chinese、Japanese
- 只有复数形式：scissors（剪刀）、tweezers（镊子）、trousers（裤子）、clothes（衣服）、congratulations

## 所有格

所有格表示 **从属关系**，有 **'s** 和 **of** 两种表达方式。**无生命的事物大多用 of**，如 the door of the room。

| | 以 s/es 结尾 | 其他结尾 |
| --- | --- | --- |
| 单数 | ' 或 's（Thomas' book / Thomas's book） | 's（John's car = the car of John） |
| 复数 | '（the boys' room） | 's（the children's toys） |

- 用 and 连接并列名词时：
    - 各自所有，每个名词都加 's：Tom's and Jack's rooms（汤姆的房间和杰克的房间）
    - 共同所有，只在最后一个名词加 's：Tom and Jack's room（汤姆和杰克共同的房间）
- 无生命的事物在以下情况也常用 's：
    - 时间、距离：three days' holiday、ten minutes' walk
    - 国家、城市：Beijing's policy
    - 机构：the airport's service guide
    - 天体：the sun's rays、the earth's surface
- 同时使用 of 和 's 构成 **双重所有格**，'s 前的名词必须指人：a friend of my father's

## 主谓一致

主语和谓语在人称和数上保持一致，判断时遵循三个原则：

| 原则 | 说明 |
| --- | --- |
| 语法一致 | 按主语的语法形式（单数或复数）决定谓语 |
| 意义一致 | 按主语在上下文中实际表示的意义决定谓语 |
| 就近一致 | 由离谓语最近的主语决定，常见于 or、either…or…、neither…nor…、there be 等句型 |

常见情况：

- 主语的单复数与谓语一致
    - I am a student.
    - They are students.
- 国家、机构、书名等专有名词的复数形式看作整体，谓语用单数
    - The United States was founded in 1776.
    - *Three Kingdoms* is a good story.
- 时间、金钱、距离等单位看作整体，谓语用单数
    - Two dollars is no big deal.
    - Four miles is not a long way.
- many a… 或 more than one + 名词作主语，谓语用单数
    - Many a man is smoking.
    - More than one man is smoking.
- one and a half + 复数名词作主语，谓语用单数
    - One and a half watermelons is in the fridge.
- 加减乘除运算中，谓语用单数
    - Five times five is twenty-five.
- each、every、one、no one，以及 some/any/no/every + body/one/thing 作主语或限定词，谓语用单数
    - Each student is in the classroom.
    - Everyone is in the classroom.
- one of + 复数名词，谓语用单数
    - One of the students in our school is from the United States.
- 集体名词表整体时谓语用单数，表其中的成员时谓语用复数
    - The family was in a poor way.
    - The family are all fond of music.
- 单复数同形的名词，根据上下文判断
    - A fish was back in the water.
    - Some fish are still alive.
- a number of + 复数名词表示“许多”，谓语用复数；the number of + 复数名词表示“……的数量”，谓语用单数
    - A number of scientists are single.
    - The number of scientists in the lab is five.
- 就近原则：离谓语近的名词决定谓语单复数
    - There is one computer and two phones.
    - Here are two apples and one banana.
