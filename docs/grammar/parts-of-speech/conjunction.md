# 连词

连词用来连接词、短语或句子，分为并列连词和从属连词。

## 并列连词

连接两个地位平等的成分，常见的有 and、but、or、so。

## 从属连词

引导从句，把从句连接到主句上。

that 引导主语从句、宾语从句、表语从句、同位语从句时只起连接作用，在从句中不充当成分，也没有实际意义，见[名词性从句](../clauses/nominal.md)。

引导[状语从句](../clauses/adverbial.md)的连词：

| 类型 | 连词 |
| --- | --- |
| 时间 | when、while、as、before、after、until、since |
| 地点 | where、wherever |
| 比较 | than、as |
| 条件 | if、unless |
| 让步 | although、though、even though、even if、while |
| 方式 | as、as if、as though |
| 原因 | because、since、as |
| 目的 | in order that、so that |
| 结果 | so … that …、such … that … |

!!! note
    - although / though 不能与 but 连用，because 不能与 so 连用。
    - 表原因时语气由强到弱：because > since（表已知或附带的原因）> as。
