# 句子成分

| 成分 | 英文 | 说明 |
| --- | --- | --- |
| 主语 | subject | 句子的主体，动作的执行者或被描述的对象 |
| 谓语 | predicate | 说明主语的动作或状态，由动词充当 |
| 宾语 | object | 动作的承受者 |
| 双宾语 | double object | 间接宾语（人）+ 直接宾语（物），如 give **me** **a book** |
| 表语 | subject complement | 即主语补足语，跟在系动词后说明主语的身份、性质、状态 |
| 宾语补足语 | object complement | 补充说明宾语，如 We made him **our leader**. |
| 定语 | attribute | 修饰名词，作用与形容词类似；但定语可以由形容词、数词、名词、现在分词、介词短语、从句等充当 |
| 状语 | adverbial | 修饰动词、形容词或整个句子，作用与副词类似，表示时间、地点、原因、方式等 |
| 同位语 | apposition | 对前面的名词作进一步解释，如 Beijing, **the capital of China** |

主语、谓语、宾语、表语、宾语补足语构成句子的主干，即[五大基本句型](patterns.md)；定语、状语、同位语是附加成分。

## 综合示例

一个简单句无法同时容纳全部成分（表语需要系动词，双宾语和宾语补足语又需要不同的动词），下面用一个复合句来演示：

> **Last Sunday**, **Tom**, **my elder brother**, **gave** **me** **a beautiful watch**, and **it made me really happy** because **the gift was a complete surprise**.

| 成分 | 句中部分 | 说明 |
| --- | --- | --- |
| 主语 | **Tom**、**it**、**the gift** | 三个分句各有一个主语 |
| 谓语 | **gave**、**made**、**was** | 三个分句各有一个谓语动词 |
| 双宾语 | gave **me**（间宾）**a beautiful watch**（直宾） | give + 人 + 物 |
| 宾语 | made **me** happy | made 的宾语 |
| 宾语补足语 | made me **really happy** | 说明宾语 me 的状态 |
| 表语 | was **a complete surprise** | 跟在系动词 was 后，说明主语 the gift |
| 同位语 | Tom, **my elder brother** | 进一步解释 Tom 是谁 |
| 定语 | **my**、**elder**、**beautiful**、**complete** | 分别修饰 brother、watch、surprise |
| 状语 | **Last Sunday**、**really**、**because the gift was a complete surprise** | 分别表示时间、程度、原因 |

```text
Last Sunday,   Tom,   my elder brother,   gave   me    a beautiful watch,
  [状语]      [主语]     [同位语]         [谓语] [间宾]     [直宾]
                       (my/elder=定语)                (beautiful=定语)

and   it     made    me     really happy
    [主语]  [谓语]  [宾语]    [宾补]
                            (really=状语)

because  the gift   was   a complete surprise      ← 整个从句作原因状语
          [主语]   [谓语]       [表语]
                            (complete=定语)
```

三个分句分别对应主谓双宾、主谓宾宾补、主系表三种基本句型。
