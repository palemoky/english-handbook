# 句子类型

## 按结构分

| 类型 | 说明 |
| --- | --- |
| 简单句 | 只有一套主谓结构，见[五大基本句型](patterns.md) |
| 并列复合句 | 两个或多个简单句用并列连词（and、but、or、so 等）连接 |
| 主从复合句 | 由主句和从句组成，从句分为名词性从句、定语从句、状语从句，见[复合句](../clauses/README.md) |

## 按用途分

### 陈述句

陈述事实或观点，分为肯定句和否定句。

### 疑问句

#### 一般疑问句

可以用 yes / no 回答。陈述句的谓语是 be 动词或含有助动词、情态动词时，把它们提到句首；否则用 do / does / did 提问。

- Do you love me?
- Is he your teacher?

#### 特殊疑问句

对句子中的某个成分提问，用特殊疑问词开头，不能用 yes / no 回答。

| 疑问词 | 提问对象 | 例句 |
| --- | --- | --- |
| who | 人 | Who's next? |
| whom | 人（作宾语） | Whom did you choose as our team leader? |
| whose | 所属 | Whose car is this? |
| what | 事物 | What time is it? |
| which | 选择 | Which is your choice? |
| when | 时间 | When can we start working? |
| where | 地点 | Where is the bathroom? |
| why | 原因 | Why did he do it? |
| how | 方式、程度 | How heavy is it? |
| how much / many | 数量 | How much longer? |

#### 选择疑问句

一般疑问句 + or + 选项，提供两个或以上的选项供选择，不能用 yes / no 回答。

- Do you like to play football or basketball?

#### 反义疑问句

在陈述句后附加一个简短的疑问句，可以用 yes / no 回答。前肯后否，前否后肯。

- He is your teacher, isn't he? (Yes, he is.)
- He isn't your teacher, is he? (No, he isn't.)

含 must 的反义疑问句要看 must 的含义：

- 表示“必须”时，附加部分一般用 needn't：You must go now, needn't you?
- 表示推测时，附加部分根据 must 后面的动词来定：He must be tired, isn't he? / She must have left, hasn't she?

### 感叹句

| 结构 | 例句 |
| --- | --- |
| What + a/an + 形容词 + 可数名词单数 + 主语 + 谓语 | What a beautiful photo it is! |
| What + 形容词 + 不可数名词 / 可数名词复数 + 主语 + 谓语 | What clean water it is!<br>What brilliant dogs they are! |
| How + 形容词 / 副词 + 主语 + 谓语 | How careful he is!<br>How fast he runs! |
| How + 形容词 + a/an + 可数名词单数 + 主语 + 谓语 | How cute a dog it is! |

### 祈使句

省略主语 you，以动词原形开头：

- 命令、警告：Get out! / Be quiet, please. / Be careful.
- 请求、祝愿：Have a nice day. / Let me help you.
