# 特殊句式

## 倒装句

### 完全倒装

整个谓语动词放在主语之前：

- 副词或介词短语位于句首时
    - 表地点的副词：here、there，如 Here comes the bus.
    - 表时间的副词：now、then，如 Then came the rain.
    - 表方向的副词：in、out、up、down、away，如 Out rushed the children.
    - 表地点的介词短语，如 On the hill stands a temple.
- 表语位于句首时，如 Gone are the days when we were young.

### 部分倒装

只把助动词、情态动词或 be 动词提到主语之前：

- 句首有否定意义的词，如 Never have I seen such a thing.
- 句首是 only + 状语，如 Only then did I realize the truth.
- 虚拟条件句省略 if，把 should / were / had 提前，如 Should it rain tomorrow, we would stay at home.
- 固定句型，如 so / neither / nor + 助动词 + 主语：I can't swim. Nor can he.

### 形式倒装

语序变化但不涉及助动词提前：

- 感叹句，如 What a beautiful day it is!
- 比较级句型
- however、whatever 引导的让步状语从句
- as、though 引导的让步状语从句，如 Young as he is, he knows a lot.

## 强调句

### 口语

通过重读和语气来强调。

### 书面

- 排版：大写、斜体、粗体、感叹号等标点
- 强调词：really、very、just、ever 等
- 句式：倒装、感叹句，以及 It is / was … that … 强调句型，如 It was Tom that broke the window.
