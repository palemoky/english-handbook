# English Handbook

怎么学英语？这个问题难住了很多人。其实只要回想一下我们是怎么学会中文的，答案就呼之欲出了：开口说，每天大量地练。

学任何语言都遵循这个规律。想更快地掌握一门语言，首先要弄清它的游戏规则：怎么发音，怎么组织句子。词汇反而是优先级最低的。每种语言的常用词汇都是有限的，只要大量使用，它们自然会带着上下文反复出现，在潜移默化中被记住。只背单词而不使用，往往前脚背、后脚忘，就算背下来了也不会用，舍本逐末，事倍功半。

到了 AI 时代，学习的门槛大大降低，学英语也方便了不少。比如我建了一个 [english-journey](https://github.com/palemoky/english-journey) 仓库，借助 AI Agent 记录和分析自己的学习过程，针对当前水平重点提升。另外，现在很多 AI 已经能流畅对话，初期完全可以直接和 AI 练口语，之后再付费找真人练习。
