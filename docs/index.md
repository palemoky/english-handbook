# English Handbook

学习任何东西，首先都不能有排斥心理。很多人因为过去的学习经历对英语留下了心理阴影，学起来非常痛苦，也始终没能真正掌握。那么，该如何克服这种排斥心理呢？我的建议是先从自己喜欢的英语内容入手，比如电影、动画、名人访谈等，让自己先对英语产生兴趣，再根据自身情况规划学习内容，而不必像在学校那样，一上来就背单词、学语法。

有了兴趣之后，具体该怎么学呢？这个问题难住了很多人。其实只要回想一下我们是怎么学会中文的，答案就呼之欲出了：开口说，每天大量地练。学任何语言都遵循这个规律。想更快地掌握一门语言，首先要弄清它的游戏规则：怎么发音，怎么组织句子。词汇反而是优先级最低的。每种语言的常用词汇都是有限的，只要大量使用，它们自然会带着上下文反复出现，在潜移默化中被记住。只背单词而不使用，往往是背了忘、忘了再背，就算记住了也不会用，事倍功半。

到了 AI 时代，学习的门槛大大降低，学英语也方便了不少。比如我建了一个 [english-journey](https://github.com/palemoky/english-journey) 仓库，借助 AI Agent 记录和分析自己的学习过程，针对当前水平重点提升。另外，现在很多 AI 已经能流畅对话，初期完全可以直接和 AI 练口语，之后再付费找真人练习。

## 学习路线

如果你是初学者，建议按下面的顺序阅读。每学完一步，就用 AI 出题、对话来练习，不必等全部学完再开口。

| 阶段 | 学什么 | 学完能做到 |
| --- | --- | --- |
| 1. 发音 | [国际音标](pronunciation/ipa/README.md)、[单词重音](pronunciation/stress/README.md) | 看音标读出任何单词 |
| 2. 句子骨架 | [句子成分](grammar/sentence-structure/elements.md)、[五大基本句型](grammar/sentence-structure/patterns.md)、[句子类型](grammar/sentence-structure/types.md) | 说出主谓宾完整的简单句，会变否定句和疑问句 |
| 3. 基础时态 | [时态](grammar/verbs/tenses.md)中的一般现在时、一般过去时、一般将来时、现在进行时，以及[主谓一致](grammar/sentence-structure/agreement.md) | 描述日常、过去的经历和将来的计划 |
| 4. 词类 | [名词](grammar/parts-of-speech/noun.md)、[代词](grammar/parts-of-speech/pronoun.md)、[冠词](grammar/parts-of-speech/article.md)、[形容词与副词](grammar/parts-of-speech/adj-adv.md)、[介词](grammar/parts-of-speech/preposition.md) | 把简单句说得更准确、更丰富 |
| 5. 自然口语 | [连读与弱读](pronunciation/connected-speech/README.md)、[语调与节奏](pronunciation/intonation/README.md)、[固定搭配](vocabulary/collocations/README.md)、[短语动词](vocabulary/phrasal-verbs/README.md) | 听懂正常语速，说话不再“一个词一个词地蹦” |
| 6. 进阶语法 | 其余时态、[情态动词](grammar/verbs/modals.md)、[非谓语动词](grammar/verbs/non-finite.md)、[复合句](grammar/clauses/README.md)、[语态](grammar/verbs/voice.md) | 读懂和写出长句 |
| 7. 查漏补缺 | [构词法](vocabulary/word-formation/README.md)、[易混词辨析](vocabulary/confusables/README.md)、[虚拟语气](grammar/verbs/subjunctive.md)、[特殊句式](grammar/special-sentences/README.md) | 扩大词汇量，理解更复杂的表达 |
