# 连读与弱读

自然语速下，英语并不是一个词一个词分开读的。词与词之间会连接、吞音、变音，虚词也会读得又轻又快。这正是“单词都认识，却听不懂”的主要原因。

## 连读

### 辅音 + 元音

前一个词以辅音结尾、后一个词以元音开头时，辅音直接与后面的元音拼读。

| 短语 | 读法 |
| --- | --- |
| an apple | a-napple |
| pick it up | pi-ki-tup |
| look at it | loo-ka-tit |
| not at all | no-ta-tall |

### 元音 + 元音

前一个词以元音结尾、后一个词以元音开头时，中间会自然加入一个过渡音：

| 前一个音 | 插入 | 示例 |
| --- | --- | --- |
| /iː/ /ɪ/ /eɪ/ /aɪ/ /ɔɪ/ 等 | /j/ | I am → I-yam，see it → see-yit |
| /uː/ /ʊ/ /əʊ/ /aʊ/ 等 | /w/ | go out → go-wout，do it → do-wit |

### r 连读

英式发音中，词尾的 r 通常不发音，但后面紧跟元音开头的词时要读出 /r/：far away /fɑːr əˈweɪ/、here and there /hɪər ən ðeə/。美式发音中 r 本来就发音，自然连在一起。

## 失去爆破

两个爆破音（/p/ /b/ /t/ /d/ /k/ /ɡ/）相邻时，前一个只做出发音的口型，不送气爆破出来，稍作停顿后直接读后一个音。

| 情况 | 示例 |
| --- | --- |
| 爆破音 + 爆破音 | good bye、sit down、big cake、that table |
| 爆破音 + 摩擦音、破擦音 | good friend、white shirt、that child |
| 爆破音 + 鼻音、舌侧音（不完全爆破） | good night、at last、get married |

## 同化

相邻的两个音互相影响，变成另一个音。最常见的是 /t/ /d/ /s/ /z/ 遇到 /j/：

| 组合 | 变为 | 示例 |
| --- | --- | --- |
| /t/ + /j/ | /tʃ/ | don't you → don-chu，last year → las-cheer |
| /d/ + /j/ | /dʒ/ | did you → di-ju，would you → wou-ju |
| /s/ + /j/ | /ʃ/ | miss you → mi-shu |
| /z/ + /j/ | /ʒ/ | as you → a-zhu |

## 省音

为了说得更顺，有些音会被省略：

- /t/ /d/ 夹在两个辅音之间时常被省略：next day → nex' day，last night → las' night，handbag → han'bag
- 非重读音节中的 /ə/ 常被省略：family /ˈfæmli/、chocolate /ˈtʃɒklət/、camera /ˈkæmrə/

## 弱读

英语中的 **虚词**（冠词、介词、连词、代词、助动词等）在句子中通常不重读，元音弱化为 /ə/ 或 /ɪ/，甚至省略。

| 单词 | 强读式 | 弱读式 |
| --- | --- | --- |
| a | /eɪ/ | /ə/ |
| an | /æn/ | /ən/ |
| the | /ðiː/ | /ðə/（辅音前）、/ði/（元音前） |
| and | /ænd/ | /ənd/、/ən/、/n/ |
| but | /bʌt/ | /bət/ |
| or | /ɔː/ | /ə/ |
| of | /ɒv/ | /əv/、/ə/ |
| to | /tuː/ | /tə/（辅音前）、/tu/（元音前） |
| for | /fɔː/ | /fə/ |
| from | /frɒm/ | /frəm/ |
| at | /æt/ | /ət/ |
| can | /kæn/ | /kən/ |
| was | /wɒz/ | /wəz/ |
| were | /wɜː/ | /wə/ |
| have | /hæv/ | /həv/、/əv/ |
| has | /hæz/ | /həz/、/əz/ |
| do | /duː/ | /də/ |
| does | /dʌz/ | /dəz/ |
| you | /juː/ | /jə/ |
| them | /ðem/ | /ðəm/ |
| some | /sʌm/ | /səm/ |
| than | /ðæn/ | /ðən/ |
| as | /æz/ | /əz/ |

以下情况要用强读式：

- 位于句末：What are you looking **at**? /æt/
- 被强调或对比：It's not for him, it's **for** you.
- 单独回答：Yes, I **can**. /kæn/

!!! tip
    can 的弱读 /kən/ 和否定 can't /kɑːnt/ 很容易混淆。肯定句中 can 轻而短，重音在后面的动词上；can't 本身重读：I can ˈswim. / I ˈcan't swim.

## 美式英语的闪音

美式英语中，/t/ 位于两个元音之间且后面的音节不重读时，会读成一个很轻的、类似 /d/ 的闪音：

- 单词内：water、better、city、party
- 跨单词：get it → ge-dit，a lot of → a-lo-dof
