# 国际音标

国内教材常用的国际音标（IPA）共 48 个：20 个元音、28 个辅音。以下按英式发音标注，美式发音的差异见[英式与美式](#英式与美式)。

## 元音

### 单元音

单元音发音时口型保持不变。

| 短元音 | 例词 | 长元音 | 例词 |
| --- | --- | --- | --- |
| /ɪ/ | sit /sɪt/ | /iː/ | see /siː/ |
| /e/ | bed /bed/ | | |
| /æ/ | cat /kæt/ | | |
| /ʌ/ | cup /kʌp/ | /ɑː/ | car /kɑː/ |
| /ɒ/ | hot /hɒt/ | /ɔː/ | door /dɔː/ |
| /ʊ/ | book /bʊk/ | /uː/ | food /fuːd/ |
| /ə/ | about /əˈbaʊt/ | /ɜː/ | bird /bɜːd/ |

- 音标中的 /ː/ 表示长音。
- /ə/ 是英语中最常见的元音，几乎只出现在非重读音节里，见[连读与弱读 · 弱读](../connected-speech/README.md#弱读)。

### 双元音

双元音由一个元音滑向另一个元音，口型有明显变化，前一个音长而响，后一个音短而轻。

## 辅音

| 类别 | 清辅音 | 浊辅音 |
| --- | --- | --- |
| 爆破音 | /p/ pen、/t/ ten、/k/ cat | /b/ bag、/d/ dog、/ɡ/ go |
| 摩擦音 | /f/ fish、/θ/ think、/s/ see、/ʃ/ she、/h/ hat | /v/ very、/ð/ this、/z/ zoo、/ʒ/ vision、/r/ red |
| 破擦音 | /tʃ/ chair、/tr/ tree、/ts/ cats | /dʒ/ jump、/dr/ dream、/dz/ beds |
| 鼻音 | | /m/ man、/n/ no、/ŋ/ sing |
| 舌侧音 | | /l/ leg |
| 半元音 | | /w/ we、/j/ yes |

- **清辅音** 发音时声带不振动，**浊辅音** 声带振动。爆破音、摩擦音、破擦音大多成对出现，口型相同，只是清浊不同，如 /p/–/b/、/f/–/v/、/s/–/z/。
- 把手放在喉咙上，发浊辅音时能感觉到振动。
- 名词复数和第三人称单数的 -s、过去式的 -ed，读音取决于前一个音的清浊：

    | 词尾 | 清辅音后 | 浊辅音和元音后 | 特殊情况 |
    | --- | --- | --- | --- |
    | -s / -es | /s/ books | /z/ dogs、plays | /s/ /z/ /ʃ/ /ʒ/ /tʃ/ /dʒ/ 后读 /ɪz/：buses、watches |
    | -ed | /t/ worked | /d/ played | /t/ /d/ 后读 /ɪd/：wanted、needed |

## 中国学习者的易错音

| 易错点 | 发音要领 | 对比 |
| --- | --- | --- |
| /θ/ /ð/ | 舌尖轻放在上下齿之间，气流从舌齿间送出；不要发成 /s/ /z/ 或 /f/ | think / sink、this / zis |
| /v/ 与 /w/ | /v/ 上齿轻触下唇；/w/ 双唇收圆，不接触牙齿 | vest / west |
| /æ/ 与 /e/ | /æ/ 嘴张得更大，嘴角向两边拉；/e/ 开口较小 | bad / bed |
| /iː/ 与 /ɪ/ | 不只是长短不同：/ɪ/ 更放松，开口略大，接近“衣”和“诶”之间 | sheep / ship |
| /n/ 与 /l/ | /n/ 气流从鼻腔出；/l/ 舌尖抵上齿龈，气流从舌两侧出 | night / light |
| /n/ 与 /ŋ/ | /n/ 舌尖抵上齿龈；/ŋ/ 舌后部抵软腭，不发出 /ɡ/ | sin / sing |
| /r/ | 舌尖向上卷但不接触上颚，双唇略圆；不要发成汉语的“日” | red、right |
| 双元音 | 要有明显的滑动，不要发成单元音 | go /ɡəʊ/ 不是 /ɡɔː/ |
| 词尾辅音 | 词尾辅音轻轻带过，不要加元音 | book 不读成“布克” |

## 英式与美式

| 差异 | 例词 | 英式 | 美式 |
| --- | --- | --- | --- |
| 元音后的 r 是否发音 | car | /kɑː/ | /kɑːr/ |
| /ɜː/ 与 /ə/ 带 r 音 | bird、teacher | /bɜːd/、/ˈtiːtʃə/ | /bɝːd/、/ˈtiːtʃɚ/ |
| /ɒ/ 读作 /ɑː/ | hot | /hɒt/ | /hɑːt/ |
| /əʊ/ 读作 /oʊ/ | go | /ɡəʊ/ | /ɡoʊ/ |
| 部分 /ɑː/ 读作 /æ/ | ask、bath、dance | /ɑːsk/ | /æsk/ |
| 集中双元音变为元音 + r | hair、here | /heə/、/hɪə/ | /her/、/hɪr/ |
| 元音间的 t 闪音化，听起来像轻 d | water、better | /ˈwɔːtə/ | /ˈwɑːtər/，听起来像 wa-der |

### KK 音标

美式英语的教材和词典常用 KK 音标，与国际音标的主要区别如下：

| 国际音标 | KK 音标 | 例词 |
| --- | --- | --- |
| /iː/ | /i/ | see |
| /e/ | /ɛ/ | bed |
| /ɑː/、/ɒ/ | /ɑ/ | car、hot |
| /ɔː/ | /ɔ/ | door |
| /uː/ | /u/ | food |
| /ɜː/ | /ɝ/ | bird |
| /ə/（带 r） | /ɚ/ | teacher |
| /eɪ/ | /e/ | day |
| /əʊ/ | /o/ | go |
