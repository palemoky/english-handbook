# 发音概览

发音可以从小到大分为四个层次，每一层都建立在前一层的基础上：

| 层次 | 关注点 | 页面 |
| --- | --- | --- |
| 音素 | 每个音怎么发，即 48 个音标 | [国际音标](ipa/README.md) |
| 单词 | 多音节词里哪个音节重读 | [单词重音](stress/README.md) |
| 短语 | 词与词之间如何连接、哪些词弱读 | [连读与弱读](connected-speech/README.md) |
| 句子 | 音调的升降、轻重的节奏 | [语调与节奏](intonation/README.md) |

单个音发得准只是第一步。很多人单词读得没问题，一说句子就“很中式”，原因往往在后三层：重音放错、每个词都读得一样重、该连的地方断开、语调平直。

## 练习方法

- **查词典听发音**：遇到生词时听真人发音，并留意音标和重音符号。Cambridge、Oxford、Longman 等词典都同时提供英式和美式发音。
- **跟读（shadowing）**：选一段带原文的音频，落后半句跟着读，模仿语调和节奏，而不只是单词。
- **录音对比**：把自己的跟读录下来，与原音逐句对比，找出差别最大的地方重点练。
- **发音评测**：用有道词典或欧路词典的跟读评测功能，给自己的发音打分，找出不标准的音（有道词典的评测是付费功能）。
- **先慢后快**：先放慢速度把每个音、每处连读读准，再逐渐提速到正常语速。
