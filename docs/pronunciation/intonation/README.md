# 语调与节奏

## 句子重音

句子中并不是每个词都重读。一般来说，承载信息的 **实词** 重读，起语法作用的 **虚词** 弱读：

| 通常重读 | 通常弱读 |
| --- | --- |
| 名词、实义动词、形容词、副词、数词、指示代词、疑问词、否定词（not、never、can't） | 冠词、介词、连词、人称代词、助动词、be 动词、关系代词 |

I ˈwant to ˈbuy a ˈnew ˈcar.

### 对比重音

说话人可以把重音放在任何一个词上来强调它，句子的言外之意随之改变：

| 句子 | 言外之意 |
| --- | --- |
| **I** didn't say he stole it. | 不是我说的，是别人说的 |
| I **didn't** say he stole it. | 我根本没这么说 |
| I didn't **say** he stole it. | 我只是暗示，没有明说 |
| I didn't say **he** stole it. | 我没说是他偷的，是别人 |
| I didn't say he **stole** it. | 我没说他偷，可能是借的 |
| I didn't say he stole **it**. | 他偷的是别的东西 |

## 节奏

汉语是 **音节计时** 的语言，每个字所占的时间大致相等；英语是 **重音计时** 的语言，重读音节之间的时间间隔大致相等，中间的非重读音节无论多少，都要压缩着快速带过。

| 句子 | 重读音节 |
| --- | --- |
| ˈCats ˈchase ˈmice. | 3 个 |
| The ˈcats have been ˈchasing the ˈmice. | 3 个 |

两句话都有 3 个重读音节，用正常语速读，所用的时间相差不多。第二句多出来的虚词都要弱读，见[连读与弱读 · 弱读](../connected-speech/README.md#弱读)。

把每个词都读得一样重、一样长，是中式口音最明显的特征之一。

## 语调

语调指一句话中音调的高低变化，主要落在句子最后一个重读音节上。

### 降调 ↘

表示肯定、完结，语气确定：

| 句型 | 示例 |
| --- | --- |
| 陈述句 | I'm from ↘China. |
| 特殊疑问句 | Where do you ↘live? |
| 祈使句 | Close the ↘door. |
| 感叹句 | What a beautiful ↘day! |

### 升调 ↗

表示疑问、不确定、未完结，或语气更礼貌：

| 句型 | 示例 |
| --- | --- |
| 一般疑问句 | Are you a ↗student? |
| 用陈述句的形式提问 | You're ↗leaving? |
| 礼貌的请求 | Could you help me ↗please? |
| 话还没说完 | When I got ↗home, I found the door ↘open. |

### 组合语调

| 句型 | 语调 | 示例 |
| --- | --- | --- |
| 选择疑问句 | 前升后降 | Would you like ↗tea or ↘coffee? |
| 列举 | 前面各项升调，最后一项降调 | I bought ↗apples, ↗bananas and ↘oranges. |
| 反义疑问句 | 附加部分用降调：希望对方确认 | It's a nice day, ↘isn't it? |
| | 附加部分用升调：确实不确定 | You've met him before, ↗haven't you? |
| 降升调 ↘↗ | 表示保留、让步或有言外之意 | The food was ↘↗good.（但是……） |

## 意群与停顿

较长的句子要按 **意群**（意思紧密相关的一组词）停顿，不能在意群内部断开。停顿通常出现在标点处、从句前、较长的主语之后：

> The man who lives next door | is a famous writer.

> If you have any questions, | please let me know.
