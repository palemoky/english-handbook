# 单词重音

多音节词中总有一个音节读得更重、更长、音调更高，这就是重音。重音放错，即使每个音都发对，对方也可能听不懂。

## 重音符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| ˈ | 主重音，标在重读音节的 **前面** | teacher /ˈtiːtʃə/ |
| ˌ | 次重音，比主重音轻 | education /ˌedʒuˈkeɪʃn/ |

非重读音节中的元音常常弱化为 /ə/ 或 /ɪ/。同一个词根，重音位置变了，元音也跟着变：

| 单词 | 音标 |
| --- | --- |
| photograph | /ˈfəʊtəɡrɑːf/ |
| photography | /fəˈtɒɡrəfi/ |
| photographic | /ˌfəʊtəˈɡræfɪk/ |

## 常见规律

以下规律适用于大多数单词，但都有例外，遇到生词仍要查词典确认。

### 双音节词

| 规律 | 示例 |
| --- | --- |
| 名词、形容词多重读第一个音节 | ˈtable、ˈhappy、ˈcountry |
| 动词多重读第二个音节 | beˈgin、deˈcide、reˈlax |

同一个词作名词和动词时，重音位置不同：

| 单词 | 名词 | 动词 |
| --- | --- | --- |
| record | ˈrecord（记录） | reˈcord（录制） |
| present | ˈpresent（礼物） | preˈsent（呈现） |
| object | ˈobject（物体） | obˈject（反对） |
| increase | ˈincrease（增长） | inˈcrease（增加） |
| produce | ˈproduce（农产品） | proˈduce（生产） |
| contract | ˈcontract（合同） | conˈtract（收缩） |

### 后缀与重音

| 规律 | 后缀 | 示例 |
| --- | --- | --- |
| 重读后缀前一个音节 | -tion、-sion、-ic、-ical、-ity、-ial、-ian、-ious | eduˈcation、deˈcision、ecoˈnomic、aˈbility、muˈsician |
| 重读倒数第三个音节 | -ate、-ise / -ize、-graphy、-logy | ˈgraduate、comˈmunicate、ˈorganize、geˈography、biˈology |
| 重读后缀本身 | -ee、-eer、-ese、-ique、-oo | emploˈyee、engiˈneer、Chiˈnese、uˈnique、bamˈboo |
| 不影响原词重音 | -ness、-ment、-ful、-less、-er、-ly、-able | ˈhappy → ˈhappiness，emˈploy → emˈployment，ˈcare → ˈcareful |

### 前缀

前缀一般不重读，重音仍在词根上：unˈhappy、reˈwrite、disˈlike。

### 复合词

| 类型 | 重音位置 | 示例 |
| --- | --- | --- |
| 复合名词 | 第一部分 | ˈblackboard（黑板）、ˈgreenhouse（温室） |
| 形容词 + 名词的短语 | 名词 | black ˈboard（黑色的木板）、green ˈhouse（绿色的房子） |
| 短语动词 | 小品词 | take ˈoff、give ˈup |
| 由短语动词转化的名词 | 第一部分 | ˈtake-off（起飞）、ˈbreakdown（故障） |

### 数字

-teen 结尾的数字重读 -teen，-ty 结尾的重读第一个音节，可以借此区分：thirˈteen / ˈthirty、fifˈteen / ˈfifty。
