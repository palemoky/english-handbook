# 术语表

本手册中常用的语法和发音术语，按主题排列。遇到看不懂的术语，可以回到这里查。

## 发音

| 术语 | 解释 | 示例 |
| --- | --- | --- |
| 音标 | 记录读音的符号，写在 / / 之间 | cat /kæt/ |
| 元音 | 发音时气流不受阻碍的音，是音节的核心 | /æ/、/iː/、/aɪ/ |
| 辅音 | 发音时气流受到舌、齿、唇等阻碍的音 | /p/、/s/、/m/ |
| 清辅音 / 浊辅音 | 发音时声带不振动 / 振动的辅音 | /p/ 清，/b/ 浊 |
| 爆破音 | 气流先被完全堵住，再突然放开发出的音 | /p/ /b/ /t/ /d/ /k/ /ɡ/ |
| 摩擦音 | 气流从狭窄的缝隙中挤出，产生摩擦的音 | /f/ /s/ /θ/ |
| 音节 | 读音的基本单位，一般以一个元音为核心 | teacher 有两个音节：tea-cher |
| 重读闭音节 | 重读的、以一个辅音字母结尾、中间只有一个元音字母的音节 | big、run、begin 中的 gin |
| 重音 | 单词或句子中读得更重、更长的音节 | ˈteacher |
| 弱读 | 虚词在句子中读得又轻又快，元音变为 /ə/ | to /tuː/ → /tə/ |
| 连读 | 相邻的两个词连在一起读 | pick it up |
| 失去爆破 | 两个爆破音相邻时，前一个只做口型不发出 | good bye |

详见[发音](pronunciation/README.md)。

## 语法

### 词

| 术语 | 解释 | 示例 |
| --- | --- | --- |
| 词性 / 词类 | 单词按用法的分类 | 名词、动词、形容词等 |
| 实词 | 有实际意义的词：名词、动词、形容词、副词、数词 | book、run、happy |
| 虚词 | 主要起语法作用的词：冠词、介词、连词、代词、助动词 | the、in、and |
| 可数名词 / 不可数名词 | 能 / 不能直接用数词修饰的名词 | an apple / water |
| 限定词 | 放在名词前限定其范围的词，如冠词、物主代词、指示代词 | the、my、this |
| 第三人称单数 | he、she、it 以及单数名词作主语，一般现在时动词要加 -s | He works. |

### 句子成分

| 术语 | 解释 | 示例 |
| --- | --- | --- |
| 主语 | 句子说的是谁或什么 | **Tom** runs. |
| 谓语 | 主语做什么或是什么，由动词充当 | Tom **runs**. |
| 宾语 | 动作的承受者 | I love **music**. |
| 表语 | 系动词后面说明主语的成分，又叫主语补足语 | She is **a teacher**. |
| 宾语补足语 | 补充说明宾语的成分 | We made him **our leader**. |
| 定语 | 修饰名词的成分 | a **red** car |
| 状语 | 修饰动词、形容词或整句，表示时间、地点、方式等 | He runs **fast**. |
| 同位语 | 对前一个名词作进一步解释 | Beijing, **the capital of China** |

详见[句子成分](grammar/sentence-structure/elements.md)。

### 动词

| 术语 | 解释 | 示例 |
| --- | --- | --- |
| 及物动词 / 不及物动词 | 后面需要 / 不需要接宾语的动词 | love sth. / cry |
| 系动词 | 连接主语和表语的动词 | be、look、become |
| 助动词 | 帮助构成时态、语态、疑问、否定的动词 | do、have、be |
| 情态动词 | 表示能力、许可、义务、推测等态度的动词 | can、must、should |
| 时态 | 动词表示动作发生的时间和状态 | 现在完成时 have done |
| 语态 | 主语是动作的执行者（主动）还是承受者（被动） | The window was broken.（被动） |
| 非谓语动词 | 不能单独作谓语的动词形式 | to do、doing、done |
| 不定式 | to + 动词原形 | to learn |
| 动名词 | 动词 + -ing，起名词作用 | **Swimming** is fun. |
| 现在分词 | 动词 + -ing，构成进行时或作定语、状语 | a **sleeping** baby |
| 过去分词 | 构成完成时和被动语态的动词形式 | done、written |
| 虚拟语气 | 表示与事实相反的假设或愿望 | If I were you… |

### 句子

| 术语 | 解释 | 示例 |
| --- | --- | --- |
| 简单句 | 只有一套主谓结构的句子 | I like tea. |
| 并列复合句 | 两个简单句用并列连词连接 | I like tea, but she likes coffee. |
| 主从复合句 | 由主句和从句组成的句子 | I know **that he is right**. |
| 从句 | 不能独立成句、充当主句某个成分的句子 | **When I got home**, it was dark. |
| 先行词 | 定语从句所修饰的名词 | the **book** that I bought |
| 关系词 | 引导定语从句的词 | who、which、that、where |
| 倒装 | 把谓语的全部或一部分放到主语前面 | Never have I seen it. |
