# 构词法

大部分英语单词都可以拆成 **前缀 + 词根 + 后缀** 三部分：

| 单词 | 前缀 | 词根 | 后缀 | 拆解 |
| --- | --- | --- | --- | --- |
| unpredictable | un-（不）、pre-（预先） | dict（说） | -able（能……的） | un + pre + dict + able → 不能预先说出的 → 不可预测的 |
| transportation | trans-（跨越） | port（拿，运） | -ation（名词） | trans + port + ation → 跨越地运送 → 运输 |
| export | ex-（出去） | port（拿，运） | | ex + port → 运出去 → 出口 |

- **词根**决定单词的核心含义。
- **前缀**改变词义（比如否定、方向、程度），一般不改变词性。
- **后缀**主要决定词性（名词、动词、形容词、副词）。

## 学习顺序

1. [前缀](prefix.md)：数量少、规律强，学会后马上就能用。
2. [后缀](suffix.md)：帮你一眼认出单词的词性，也是理解词性变化的关键。
3. [词根](root.md)：数量最多，建议在背单词时遇到一个记一个，再回来对照。
