# 前缀

英语中最常用的 56 个前缀。前缀通常只改变词义，不改变词性。词源和词性缩写见[符号说明](README.md#符号说明)。

## 按含义归类

| 含义 | 前缀 |
| --- | --- |
| 否定 | an-, un-, in-, im-, il-, ir-, mis-, dis-, de-, non- |
| 使得 | en- |
| 对立，对抗 | anti-, contra-, counter- |
| 超过，过度 | ex-, extra-, out-（还有外面之意）, over-（还有在...之上） |
| 前面的 | fore- |
| 后面的 | back- |
| 相互的，两者之间 | inter- |
| 坏的 | mal-, mis- |
| 重复，再次 | re- |

## 反义前缀

| 前缀 | 反义前缀 |
| --- | --- |
| in-(im-, il-, ir-) 进入，如import | ex- 出去，如export |
| pre- 之前，如preview | post- 之后，postgraduate |
| pro- 支持，如pro-government | anti- 反对，如anti-war |
| en-(em-) 使...进入状态，如encrypt | de- 去除，离开，如decrypt |
| hyper- 超过，过度，如hyperactive | hypo-下面，不足，如hypoactive |
| macro- 大的，如macroeconomics | micro- 小的，如microeconomics |
| mono- 单一的 | poly- 多的 |
| super- 在...之上，如superscript | sub- 在...之下，如subscript |
| inter- 之间，如international | intra- 内部，如intranational |
| mal- 坏的，如malfunction | bene- 好的，如benefit |
