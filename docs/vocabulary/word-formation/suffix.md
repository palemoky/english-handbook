# 后缀

英语中最常用的 46 个后缀。后缀通常决定单词的词性，含义列中的「～」代表词根或词干。词源和词性缩写见[符号说明](README.md#符号说明)。

## 后缀与词性

后缀是判断词性最直接的线索。有些后缀只构成一种词性（如 -ness 一定是名词），有些后缀能构成多种词性（如 -ate 可以是形容词、名词或动词）。下图中，圆圈重叠的部分就是能构成多种词性的后缀：

### 形容词 → 名词

| 形容词后缀 | 名词后缀 | 例子 |
| --- | --- | --- |
| -able / -ible | -ability / -ibility | readable（可读的）→ readability（可读性）<br>visible（可见的）→ visibility（可见度） |
| -ant / -ent | -ance / -ence | dominant（占优势的）→ dominance（优势）<br>persistent（坚持的）→ persistence（坚持） |
| -al | -ity / -ation | formal（正式的）→ formality（正式）<br>real（真实的）→ reality（现实） |
| -ic | -ism / -ity | heroic（英勇的）→ heroism（英雄主义）<br>electric（电的）→ electricity（电） |
| -ive | -ion / -ity | active（活跃的）→ action（行动）/ activity（活动）<br>creative（有创造力的）→ creation（创造）/ creativity（创造力） |
| -ous | -ion / -osity | curious（好奇的）→ curiosity（好奇心）<br>generous（慷慨的）→ generosity（慷慨）<br>cautious（谨慎的）→ caution（谨慎）<br>ambitious（有雄心的）→ ambition（雄心） |

### 动词 → 名词

| 动词后缀 | 名词后缀 | 例子 |
| --- | --- | --- |
| -ate | -ation | create（创造）→ creation（创造）<br>educate（教育）→ education（教育） |
| -ify | -ification | clarify（澄清）→ clarification（澄清）<br>simplify（简化）→ simplification（简化） |
| -ize | -ization | organize（组织）→ organization（组织）<br>modernize（使现代化）→ modernization（现代化） |

### 名词 → 形容词

| 名词后缀 | 形容词后缀 | 例子 |
| --- | --- | --- |
| -or / -er | -ory / -ary | auditor（旁听者）→ auditory（听觉的）<br>supervisor（主管）→ supervisory（监督的） |
| -ist | -istic | artist（艺术家）→ artistic（艺术的）<br>optimist（乐观者）→ optimistic（乐观的） |
| 名词本身 | -y | milk（牛奶）→ milky（乳白色的）<br>silk（丝绸）→ silky（丝滑的）<br>water（水）→ watery（水汪汪的） |

### 名词 → 动词

| 名词后缀 | 动词后缀 | 例子 |
| --- | --- | --- |
| -th | -en | strength（力量）→ strengthen（加强）<br>length（长度）→ lengthen（延长） |

### 动词 → 形容词

| 动词后缀 | 形容词后缀 | 例子 |
| --- | --- | --- |
| -e / -ate | -able / -ible | compare（比较）→ comparable（可比较的）<br>irritate（激怒）→ irritable（易怒的） |
