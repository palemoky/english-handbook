# 固定搭配

固定搭配（collocation）指英语母语者习惯放在一起使用的词。这些组合往往没有道理可讲，换成意思相近的词，语法上没错，听起来却很别扭。比如“大雨”是 heavy rain，不是 big rain；“浓茶”是 strong tea，不是 thick tea。

记单词时连同它的常用搭配一起记，比单独记一个词更有用。

## 中式英语常见错误

| 中文 | ✗ 直译 | ✓ 地道搭配 |
| --- | --- | --- |
| 大雨 | big rain | heavy rain |
| 浓茶 | thick tea | strong tea |
| 学习知识 | learn knowledge | gain / acquire knowledge |
| 开灯 | open the light | turn on the light |
| 吃药 | eat medicine | take medicine |
| 看书 | see a book | read a book |
| 玩电脑 | play computer | play computer games / use the computer |
| 犯错误 | do a mistake | make a mistake |
| 做作业 | make homework | do homework |
| 交通拥挤 | crowded traffic | heavy traffic |
| 高价 | expensive price | high price |
| 提高水平 | raise level | improve one's level |

## make 与 do

两者都可以译为“做”，大致区别是：make 侧重 **创造、产生** 出某种结果，do 侧重 **执行** 某项活动或工作。但很多搭配只能靠记。

| make | do |
| --- | --- |
| make a mistake（犯错） | do homework（做作业） |
| make a decision（做决定） | do the dishes（洗碗） |
| make a plan（制定计划） | do business（做生意） |
| make money（赚钱） | do exercise（锻炼） |
| make a noise（发出声音） | do research（做研究） |
| make friends（交朋友） | do your best（尽力） |
| make progress（取得进步） | do sb. a favor（帮某人一个忙） |
| make an effort（努力） | do damage（造成损害） |
| make a phone call（打电话） | do the shopping（购物） |
| make sure（确保） | do the laundry（洗衣服） |

## have、take、get、give

这几个动词本身意思很虚，常与名词搭配表示一个具体动作：

| 动词 | 搭配 |
| --- | --- |
| have | have breakfast、have a rest、have a good time、have a look、have a try、have fun |
| take | take a photo、take a shower、take a break、take a seat、take notes、take a bus、take care |
| get | get married、get lost、get ready、get a job、get the point、get home |
| give | give a speech、give advice、give sb. a hand、give up、give a call、give a presentation |
