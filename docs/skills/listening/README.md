# 听力

## 为什么听不懂

单词都认识却听不懂，原因通常不是词汇量，而是以下几点：

| 原因 | 说明 | 对应内容 |
| --- | --- | --- |
| 连读、弱读 | 实际读音和单个单词的读音差别很大 | [连读与弱读](../../pronunciation/connected-speech/README.md) |
| 自己的发音不准 | 你以为的读音和真实读音不一样，听到时对不上 | [国际音标](../../pronunciation/ipa/README.md)、[单词重音](../../pronunciation/stress/README.md) |
| 反应速度慢 | 听到后还在脑中翻译成中文，下一句已经过去了 | 多听，直到不经翻译就能理解 |
| 长句结构 | 理解不了从句和长修饰语 | [复合句](../../grammar/clauses/README.md) |

## 练习方法

### 精听

选一段 1～3 分钟、略高于自己水平的音频，逐句反复听：

1. 不看原文听一遍，了解大意
2. 逐句听写，听不出的地方多听几遍
3. 对照原文，找出没听出来的地方，分析原因：是生词、连读，还是自己读音不对
4. 跟读，模仿发音和语调，直到能跟上原速

精听很慢，但能真正提高听力，每天 15～30 分钟即可。

### 泛听

选择能听懂 70% 以上的材料，不求每个词都懂，重在大量输入、熟悉语速。通勤、做家务时都可以听。

### 字幕的使用

看剧学英语时，可以按这个顺序逐步去掉对字幕的依赖：中英字幕 → 英文字幕 → 无字幕。同一集反复看，比换着看很多集效果更好。

## 材料推荐

| 水平 | 材料 |
| --- | --- |
| 入门 | VOA Learning English（语速慢、用词简单）、儿童动画 |
| 初级 | BBC Learning English 的 6 Minute English、有声读物 |
| 中级 | TED 演讲、播客、情景喜剧（如 *Friends*） |
| 高级 | 新闻、纪录片、电影 |

也可以让 AI 根据你的水平和兴趣生成听力材料，再用语音朗读出来。
