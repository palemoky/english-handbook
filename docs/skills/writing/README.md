# 写作

## 从句子开始

写作的基础是写出正确的句子，而不是背模板：

1. 用[五大基本句型](../../grammar/sentence-structure/patterns.md)写简单句，确保主谓宾完整
2. 加上定语、状语，把句子写得更具体
3. 用连词和[复合句](../../grammar/clauses/README.md)把短句连成长句
4. 用连接词把句子组织成段落

## 写完后检查

初学者最常见的错误集中在以下几处，写完后可以逐项检查：

| 检查项 | 常见错误 | 参考 |
| --- | --- | --- |
| 主谓一致 | He go to school. → He **goes** to school. | [主谓一致](../../grammar/sentence-structure/agreement.md) |
| 时态 | Yesterday I go there. → Yesterday I **went** there. | [时态](../../grammar/verbs/tenses.md) |
| 名词单复数 | two book → two **books**；many informations → much **information** | [名词](../../grammar/parts-of-speech/noun.md) |
| 冠词 | I am student. → I am **a** student. | [冠词](../../grammar/parts-of-speech/article.md) |
| 中式搭配 | learn knowledge → **gain** knowledge | [固定搭配](../../vocabulary/collocations/README.md) |
| 连词 | Although…, but… → 只保留一个 | [状语从句](../../grammar/clauses/adverbial.md#不能同时使用的连词) |
| 句子完整性 | Because I was tired.（只有从句，没有主句） | [复合句](../../grammar/clauses/README.md) |

## 常用连接词

| 作用 | 连接词 |
| --- | --- |
| 列举 | first、second、then、finally |
| 补充 | and、also、in addition、moreover |
| 转折 | but、however、although、on the other hand |
| 因果 | because、so、therefore、as a result |
| 举例 | for example、such as |
| 总结 | in short、in conclusion |

## 用 AI 修改

写完后让 AI 修改，是目前最高效的练习方式之一。比起直接要一篇改好的文章，下面这种提问方式能让你学到更多：

> 请修改下面这段英文中的语法和用词错误。对每处修改，说明原来错在哪里、为什么这样改。不要改变我的原意，也不要使用超出我水平的高级词汇。

坚持写日记是很好的起点：每天几句话，记录当天的事，写完让 AI 修改，再把改好的版本读几遍。
